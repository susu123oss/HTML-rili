# Codex Web GPT 守护管理

双击本目录中的 `Codex Web GPT 守护管理.lnk`，窗口中选择：

- **是**：安装或重新安装每分钟运行的后台守护任务。
- **否**：卸载守护任务及其工作脚本；Codex Web GPT 程序和原有开机自启设置不变。
- **取消**：不作修改。

如需桌面入口，仅将 `.lnk` 快捷方式复制到桌面根目录。请保留本目录中的 `manager.vbs`、`watchdog.vbs` 和 `watchdog.ps1`，快捷方式会从这里读取安装文件。`wscript.exe` 是 Windows 自带程序，无需复制。

守护任务仅在 Windows 用户登录后运行；本地桥接 `127.0.0.1:17841` 与启动器均停止时，会以隐藏模式重新启动 Codex Web GPT。已经运行的启动器不会被强制关闭。
