# 智能工作日历备忘录 — Rust + GPUI 原生桌面客户端

基于 **Rust + GPUI (`0.2.2`, Direct3D 11 硬件加速渲染)** 重构的原生桌面客户端，完整支持 **管理端（全局督办）** 与 **员工端（一屏工作台）** 双角色架构，并与线上生产服务器 (`http://45.205.25.3:8090/api`) 实时互通。

---

## ✨ 核心特性

### 1. 双角色自适应架构（管理端 & 员工端）
- **👑 管理端（`admin`）**：
  - **团队执行力风云榜**：顶部展示金/银/铜牌团队成员完成率排行榜，支持展开/收起及点击成员卡片直接筛选日历。
  - **大尺寸日历卡片**：采用宽裕高度（`min-height: 165px`）与纵向平滑滚动，完整展示多位团队成员的每日事项、归属标签与审阅印章。
  - **原位督办闭环**：在日历卡片或事项详情弹窗中可一键执行 **「✓ 已阅」**、**「👍 点赞」**、**「⚡ 下发催办」**，实时触发员工端通知。
- **🧑‍💻 员工端（一线成员）**：
  - **一屏全览免滚动日历**：自动计算当月周数（35 格 5 行或 42 格 6 行），采用 `flex_1` 自适应高度填满工作区，无需上下滚动即可一眼看全整月工作安排。
  - **月份切换栏顶部居中**：`< 2026年9月 > 今天` 切换器内嵌于日历卡片头部正中央，最大化释放日历卡片纵向空间。
  - **顶部认可横幅与日历闪烁定位闭环**：收到管理端「已阅」或「点赞」后，顶部弹出翡翠绿横幅，点击后自动跳转至对应月份并在目标日历格子与事项上执行双色高亮边框脉冲闪烁，底部配有 `◀ 上一条 / 下一条 ▶` 跨月巡检分页条。
  - **未完成事项一键结转**：未完成事项右侧及详情弹窗内均配有 **`↪ 转到下一天`** 按钮，一键顺延并保留原记录。

### 2. 多维视图与深浅双主题
- **📅 工作日历视图**：支持单月视图 / 双月联排、关键词实时搜索、成员筛选。
- **📋 周计划与周报**：7 天周计划看板 + 四象限周报编辑器，支持 **「✨ 从本周日历自动汇总生成周报」** 并保存至云端。
- **📊 研发效能看板**：核心 KPI 指标卡 + 研发团队成员效能矩阵，点击任意成员可穿透回日历视图。
- **🔔 待办事项提醒**：仅统计待办/逾期/催办事项（严格排除「已阅/点赞」通知），支持一键全部完成或单条转到下一天。
- **☀️/🌙 浅色与深色主题**：随时一键切换。

## 🚀 快速运行

### 直接运行已编译程序
在 `gpui-client` 目录下已生成原生可执行文件 `work-calendar-gpui.exe`：
```powershell
# 启动登录界面（含管理端/员工端一键快捷登录按钮）
.\work-calendar-gpui.exe

# 直接以「管理端 (admin)」身份启动
.\work-calendar-gpui.exe --admin

# 直接以「员工端 (杨振)」身份启动
.\work-calendar-gpui.exe --employee
```

### 从源码编译
```powershell
$env:PATH = "C:\Users\Administrator\scoop\apps\mingw\current\bin;C:\Users\Administrator\scoop\apps\rustup\current\.cargo\bin;$env:PATH"
cargo run
```
